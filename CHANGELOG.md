# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-08-31

### Added

- Initial working version of `osrs-lib-hiscores`.
- `HiscoreClient` with overloaded `.get()` method for accessing players and leaderboards in one call.
- `AccountType`, `Activity` and `Skill` enums.
- 100% test coverage across src/*.
- Taskfile for local development with lint/type/fix/test/build commands.
- Example scripts in `examples/`.
